# Kodik API — обзор

> Источник: [bd.kodikres.com/api/info](https://bd.kodikres.com/api/info)

API предназначено для удобного получения любой информации из базы Kodik.
Использовать API можно для обновления сайта, создания специализированного сервиса и т.д.

## Базовый URL

Все запросы должны направляться к домену **`kodik-api.com`**.

```
https://kodik-api.com/...
```

## Формат данных

Все данные возвращаются в формате **JSON**.
Если вы не знаете, как работать с этим форматом, скорее всего вам лучше подойдёт скрипт автодобавления.

## Протокол и методы

- API поддерживает запросы как по **HTTP**, так и по **HTTPS**.
- Параметры можно передавать как через **GET**, так и через **POST**.
- Используйте те способы, которые вам больше подходят.

## Ресурсы

На данный момент доступны следующие типы ресурсов:

### 1. `/qualities`

Предназначен для получения всех возможных качеств.

→ [Документация по `/qualities/v2`](./qualities.md)

### 2. Справочники

- `/translations/v2` — озвучки
- `/countries` — страны
- `/genres` — жанры
- `/years` — годы

Предназначены для получения всех возможных значений материала.
Можно использовать фильтры и настройки для получения информации только для части материалов.

→ [Документация по `/years`](./years.md)  
→ [Документация по `/genres`](./genres.md)  
→ [Документация по `/countries`](./countries.md)  
→ [Документация по `/translations/v2`](./translations.md)

### 3. `/list`

Предназначен для парсинга большого количества материалов (или всех материалов сразу).
Можно фильтровать материалы по практически любому параметру.

→ [Документация по `/list`](./list.md)

### 4. `/search`

Предназначен для поиска фильма в базе.
Поиск может быть как по точным параметрам фильма, так и по нечёткому названию.

→ [Документация по `/search`](./search.md)

## Параметры `/search` и `/list`

`/search` и `/list` имеют огромное количество доступных для изменения параметров — вы сможете подобрать необходимый функционал.

Если какого-то функционала не хватает, можно написать в поддержку Kodik — они постараются добавить его как можно скорее.
