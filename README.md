# Track Anime

Track Anime — веб-приложение для просмотра аниме с интеграцией Shikimori и Kodik.
Пользователи входят через Shikimori, выбирают озвучку, смотрят серии во встроенном Kodik-плеере, ведут историю просмотра и синхронизируют списки.

- Сайт: https://ta.dygdyg.ru/
- Зеркало/автовыбор сервера: https://track-anime.github.io/
- Основной домен: https://track-anime.dygdyg.ru/

Список зеркал для автовыбора правится в [`mirrors.json`](mirrors.json) (порядок = порядок проверки).

## Возможности

| Раздел | Что делает |
|---|---|
| Лента релизов | Показывает новые серии и каталог с бесконечной прокруткой |
| Страница аниме | Метаданные Shikimori, выбор озвучки, плеер Kodik, история позиции |
| Поиск | Быстрый и расширенный поиск по локальному каталогу |
| Списки | Синхронизация пользовательских списков Shikimori |
| История | Продолжение просмотра по сезону, серии и позиции |
| Календарь | Расписание ongoing-аниме |
| Профили | Публичные страницы пользователей по Shikimori ID |
| Уведомления | Browser push, in-app лента и внешние каналы |
| PWA | Установка сайта как приложения |
